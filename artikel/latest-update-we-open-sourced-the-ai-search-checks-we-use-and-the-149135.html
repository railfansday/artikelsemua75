It has been revealed that "Block the AI bots" is one line in most robots.txt files, and it hides a real distinction. OpenAI documents separate crawlers: GPTBot for model training, OAI-SearchBot for the ChatGPT search index, ChatGPT-User for fetches when a user asks about a page. Blocking GPTBot does not remove you from ChatGPT search. Blocking OAI-SearchBot does. Anthropic splits them the same way (ClaudeBot, Claude-SearchBot, Claude-User). Perplexity has PerplexityBot for search and Perplexity-User for user fetches, and claims the second generally ignores robots.txt (docs). OpenAI's list is here.

Sources indicate that ai-crawler-access applies the robots.txt rules per crawler (named group beats *, longest rule wins, Allow wins a tie, wildcards) and labels each one as search, user-fetch or training. It can also send one request per bot user-agent string and tell you if your CDN answers 403 to a bot that robots.txt allows. Here is what it printed for our own home page:. We ran schema-check on our own home page before publishing. It reads the raw HTML, the way a crawler that does not run JavaScript sees it, and printed six findings: no WebSite entity, no description on the Organization, and no availability on four of our Offer entries. All six are real. We have not fixed them yet. (Related: Hugging Face Reads, Feb. 2021 - Long-range Transformers...)

In a recent development, the Anthropic provider was tested live. Gemini, OpenAI and Perplexity are written from the vendors' docs and tested on recorded fixtures only. 28 offline tests cover the robots.txt matcher, llms.txt rules, JSON-LD parsing and the logic of the gap and brand audits.

Recent findings suggest that illyism/seo-skills is the broader repo: 30 skills across technical SEO, content, links and copy, with far more traction. We read it before writing ours and did not copy from it. Three of its AI-search skills (aiseotracker, ai-seo-report, content-coverage) use the AI SEO Tracker service, and seo-roast checks robots.txt and fetches a page as four AI user-agents with curl. Ours are runnable scripts for per-crawler verdicts, llms.txt and JSON-LD. If you need on-page SEO or link building, use his.

The skills check one site at a time and leave the writing of the fixes to you. CitedBy crawls the whole site up to your blueprint's page limit and gives the exact fix per page. The first check is free: citedby.eu.

If one of the checks is wrong on your site, open an issue with the URL. We treat a check that is false on more than one page in ten as not measured.
