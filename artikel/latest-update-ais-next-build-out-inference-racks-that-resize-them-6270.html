Memory pooling is fast becoming one of the sharpest tools in AI inference economics, with companies racing to wring more output from every graphics processing unit. (Related: How we sped up transformer inference 100x for 🤗 API cus...)

Recent findings suggest that most AI servers still ship with a fixed GPU-to-memory ratio that holds for the life of the machine. But that is a poor fit when nobody knows what model they will deploy six months from now, according to Sumit Puri (pictured), co-founder and chief technical officer of Liqid Inc. (Related: How to train a latest language model from scratch using...)

Industry observers note that “Our core fundamental technology is around pooling and sharing the most critical resources in the data center, which are now GPU and memory,” Puri said. “Rather than statically deploying these things inside of a server, our vision is simple. Let’s put pools of resources in the rack, GPUs and memory, and dynamically assign them to any server that needs it based upon the model or the workload that we are looking to deploy.”.

According to recent reports, puri spoke with theCUBE Research’s John Furrier and Gemma Allen at SC26, during an exclusive broadcast on theCUBE, SiliconANGLE Media’s livestreaming studio. They discussed pooling GPUs and memory, the tokenomics of AI inference and Liqid as a Service. (* Disclosure below.).

Sources indicate that liqid measures payoff in tokenomics, with the yardsticks being tokens per second, tokens per watt and, above all, tokens per dollar. Supply is another pressure point in the AI infrastructure build-out, with memory among its most constrained components. But delivering only the memory each application needs stretches scarce supply further, Puri explained.

“Supply chain is a massive constraint for all of us — memory being a giantly massive constrained thing,” he noted. “If we can do things like pool memory, share memory, optimally deliver memory to the server in the right amount of memory as required by the application, we can directly address some of those supply chain problems.”.

Liqid is also widening how customers buy memory pooling. At SC26, the tech giant confirmed Liqid as a Service, a fully managed, single-tenant offering, and it is moving toward preconfigured appliances. The bet is that most enterprises will deploy models rather than build them and therefore require their own capacity, according to Puri.

“The world went to unlimited consumption of minutes, and that’s where we believe tokens are headed,” Puri said. “Everybody’s going to own their own token machine so they can consume these tokens at will.”.
