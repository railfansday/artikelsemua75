1Password says it was hacked but customers' vaults are safe

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

The attacker wasn't able to access people's vaults.

1Password has admitted that an attacker was able to infiltrate its system and steal some customer data, but it has assured consumers in its announcement that their vaults and logins are safe. On November 19, the tech giant started investigating signs that an employee's corporate GitHub account had been compromised. The company found that the attacker used that account to access its source code and inject malicious code to its backend. (Related: Porting fairseq wmt19 translation system to transformer...)

In a recent development, the attacker was then able to download customers' data, including people's names and email addresses, the dates their accounts were created and their last sign-in times. They were also able to steal owners' public keys, but 1Password said it has no impact to their security. While the bad actor was also able to steal source code from the manufacturer itself, it doesn't contain customer data. (Related: How we sped up transformer inference 100x for 🤗 API cus...)

Industry observers note that "Your vault data, the items in them, and the keys that protect them are safe and were not affected," 1Password wrote. The service doesn't have access to users' actual passwords, recovery keys and other credentials, as well as the secret keys that protect their vaults, so the attacker wasn't able to steal them. Since discovering the breach, 1Password has revoked the stolen token, disabled the affected GitHub account and added new detection tools for similar attacks.

According to recent reports, while 1Password mentioned that customers' vaults remain safe, the tech giant still advises being vigilant when it comes to phishing attempts. It warned that since users' emails were compromised in the breach, they could be used in attempts to grab people's passwords through fake account recovery and invitation emails.
