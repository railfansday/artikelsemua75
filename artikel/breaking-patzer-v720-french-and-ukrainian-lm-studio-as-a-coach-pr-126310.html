📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Last week Patzer got single sign-on. This week it got two more languages, a third local LLM provider, and a coach that stopped telling my kids they won material when they traded a bishop for a knight.

v7.20.0 is out: https://github.com/SikamikanikoBG/patzer/releases/tag/v7.20.0.

It has been revealed that @SaberGuirat and @OnyxOracle did the two substantial localizations. Not just the buttons and menus — the whole product speaks the language now: the Learn lessons (including kid mode), the move explanations, the hints, the Game Review. French piece names ("le cavalier prend le pion en e5", "petit roque"), Ukrainian with all four plural forms and declined piece names. The same guard that keeps the coach from praising a blunder runs in every language. (Related: How to train a new language model from scratch using Tr...)

The setup screen's language picker is now a grid, so all seven languages (EN, BG, ES, DE, RU, FR, UK) fit. And the navigation no longer collapses to icons when it overflows — it scrolls sideways and keeps your current page in view. (Related: How to generate text: using different decoding methods ...)

If you run LM Studio instead of Ollama or vLLM, point Patzer at it in Admin → System (localhost:1234 by default, host.docker.internal from the container). Full OpenAI-compatible completions and JSON structured outputs: move explanations, threat analysis, game reviews, automatic model listing, connection test. @66ton99 wrote it, including the integration test suite.

It has been revealed that this one is my favourite. Three facts the coach was handed wrong — and phrased confidently, because that's what LLMs do:.

According to recent reports, the fix is the architecture I keep coming back to: the server works out the facts with chess.js and Stockfish, the model only turns them into words. A wrong fact can't come out of the model's mouth any more confidently than a right one — because the model never gets to decide what's true.
