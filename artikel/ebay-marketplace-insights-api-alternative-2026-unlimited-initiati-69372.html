Marketplace Insights itself is a limited release, so if you were not let in, you can map its item_sales/search fields to this API and keep your code almost unchanged.

I'm James from the eBay Sold Listings API team. Most of the developers who write to us arrive the same way: they designed a pricing feature around Marketplace Insights, applied, and then waited. This post is the migration I would want in that situation.

Marketplace Insights is eBay's only first-party API for sold items. Its item_sales/search method returns items sold in the last 90 days. The catch is access. It sits in eBay's Buy API family, which eBay describes as limited release and intended for eBay partners, and eBay states plainly that there is no guarantee an application will be approved. Two details to watch while migrating:.

Sources indicate that one habit from Marketplace Insights does not carry over well: long queries. eBay matches every word you send, so a full listing title often returns very little. Start with brand plus model, or card name plus set and number.

Marketplace Insights was meant for apps that price a lot of items, so request quotas matter. The Unlimited initiative has no monthly request cap. A repricer, a valuation app or a nightly catalogue refresh can run on it without buying requests in blocks or watching an allowance. Batch jobs (up to 100 keywords per job, one CSV download) make large refreshes simple to schedule, and only successful requests count; errors are never billed. Details are on ebaysoldlistingsapi.com. If you are sizing a big workload, Unlimited eBay Sold Data API (2026) shows how to count it yourself.

Is there an official way to get eBay sold items without Marketplace Insights? Not from eBay today. The Browse API returns active listings only and the Finding API's findCompletedItems was retired in February 2025. A third-party sold-listings API is the route that does not need approval.

In a recent development, how long does it take to switch? For most apps, an afternoon. The adapter above keeps your Marketplace Insights shaped objects, so the rest of your code does not move.

Industry observers note that does it cover more than the US? Yes. Pass ebaySite for any of the 8 supported eBay sites. Prices come back in that site's local currency.

In a recent development, can I keep Marketplace Insights if I get approved later? Yes. Keep the adapter interface and point it at whichever source you prefer. Many teams run a sold-listings API for the extras (Best Offer prices, CSV, batch) either way.

Recent findings suggest that is there an unlimited initiative for high volume? Yes. The Unlimited plan has no monthly request cap. You can start free and move up from the dashboard when your volume needs it; your key and code stay the same.

It has been revealed that what does a failed request cost? Nothing. Every error response, including 5xx, is free. Retry 429, 502, 503 and 504 with backoff and a 90 second client timeout.
