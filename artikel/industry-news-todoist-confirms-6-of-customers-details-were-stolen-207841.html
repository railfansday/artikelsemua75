📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

It has been revealed that task management app Todoist mentioned on Tuesday that a hacker gained access to its production systems and stole customer data, including email IDs, password hashes, and account creation dates. The tech giant said around 6% of its customers were affected and blamed stolen credentials for the breach.

Todoist stated the attacker used stolen credentials to access the company’s version control system and source code between November 22 and 23. The hacker then changed employee access controls and reached the app’s cloud infrastructure via an employee’s work account. (Related: Porting fairseq wmt19 translation system to transformer...)

In a recent development, the hacker downloaded credentials of early Todoist users whose passwords were stored using an older hashing method, but didn’t change any source code, the tech giant said. Todoist said it has blocked the attack path and reset passwords as a mitigation step, as well as disabled the Todoist for Outlook email add-on. (Related: How to train a latest language model from scratch using...)

For a small number of people, about 0.001% of its userbase, the hacker also searched through tasks, comments, and attachment names to look for credentials for other services, like API keys and access tokens.

The hacker also pulled Todoist API tokens and Slack integration tokens, and looked for emails, addresses, and attachment file names through the Todoist for Outlook extension if it was connected to accounts and had permission to read emails.

According to recent reports, the company mentioned it has sent a notice to those affected and asked them to reset their credentials and change their login details in other places with the same password. The company is asking users to also update API tokens, reconnect integrations, and revoke or replace any access keys, recovery phrases, or credentials they had stored in Todoist comments.

Todoist noted it has also reset its internal access structure and how remote command execution works in its cloud environment to prevent such incidents in the future.

Todoist’s founder and CEO Amir Salihefendić apologized to customers about the incident on X, and mentioned the tech giant will take a closer look at why it happened.

The to-do app’s data breach is the latest in a burgeoning list of data breaches in which hackers use stolen credentials to access data and systems at enterprises. So far this year, we’ve seen several companies fall victim to this form of attack, including Uber and Klue.
