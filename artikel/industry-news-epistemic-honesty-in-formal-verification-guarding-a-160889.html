“Formally verified” never means “bug-free.” If a formal machine model omits dynamic linking, multithreading, or x86/ARM hardware quirks, bugs can still hide in the gap between the spec and reality. Furthermore, allowing an agent to patch code to make a theorem provable introduces reward-hacking risks (Anthropic). To uphold engineering integrity, Anthropic penalized patch edits, logged and audited all code changes, disclosed exact RISC-V/musl assumptions, and withheld proofs for unpatched vulnerabilities pending upstream fixes.
