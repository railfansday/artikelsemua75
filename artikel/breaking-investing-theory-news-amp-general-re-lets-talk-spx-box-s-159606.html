I use the Synthetic Fi website as well since boxtrades hasn't been updated in a few weeks. Last Friday I got a 7-8k SPX short box exp 3/19/27 for 984.6. Synthetic Fi was actually quoting a bit lower like around 984 last Friday, so I generally try to start with a more aggressive limit order and then walk my price down by 5 cent increments every few seconds (Schwab does have a "walk limit order" tool for this, however in its current iteration it's not useful for box spreads because the lowest increment you can use is $1, which is way too large of a walk to get the best box spread fill IMO).
