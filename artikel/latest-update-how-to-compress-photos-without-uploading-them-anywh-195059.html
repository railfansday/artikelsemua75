Recent findings suggest that most free image compressors work the same way: you upload your photo to someone's server, wait, then download a smaller copy. That's fine for a meme. It's less fine for a passport scan, a contract photo or pictures of your kids.

Industry observers note that modern browsers can do the compression themselves. The image is decoded and re-encoded on your own device, using the same canvas and WebAssembly tools that power web apps, so the file never leaves your computer or phone. Sources indicate that open your browser's developer tools, go to the Network tab and run a compression. If you see your file going out in a request, it was uploaded. With an in-browser tool you won't.
