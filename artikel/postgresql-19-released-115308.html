The PostgreSQL Global Development Group has revealed the release of PostgreSQL 19. Notable features in this release include the introduction of the REPACK (CONCURRENTLY) command to optimize tables without disruption to ongoing operations, better control over blueprint stability and query performance with the new pg_plan_advice extension, and a number of performance improvements.
