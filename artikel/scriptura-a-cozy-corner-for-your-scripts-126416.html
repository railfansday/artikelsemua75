I’ve created a upcoming little tool to help run and manage scripts in a folder tree, called scriptura. It is based on the idea behind sd and is made for fish customers.

If I type in scriptura run os upgrade linde, it will run the script at ~/scripts/os/update/linde, whilst providing tab completion for each element. Pressing tab after a script has been resolved will first add -- to clearly show the end of the script part of the command line, then use the default shell filename completion.
