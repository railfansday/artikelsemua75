Cuy Sheffield, head of Visa Crypto Labs, declared a new version of Visa CLI on November 22, 2026, an agent wallet that lets US consumers verify AI agents with eligible Visa cards and work with them to earn OUSD, a dollar stablecoin, through creative tasks.

Industry observers note that the Visa CLI product page presents a three-step flow: connect an existing agent, verify it through the owner’s card and receive task payouts. Claude Code, Codex and Hermes connect through Visa CLI on the same computer, while Grok Bot uses a hosted connection, according to the integration guide. Illustrated tasks include creating generative art, writing songs, producing launch videos and giving feedback on an agent wallet. Enrollment requires the owner to enter card details in fields hosted by a card vault, the firm handling card data and tokens for Visa CLI, and complete a one-time-code check with the bank. The card documentation says Visa CLI receives a token rather than the card number, expiry and security code. After approval, the agent receives a signing key. Visa holds the private key in isolated hardware that it never leaves, while the public key is published for verification, the enrollment guide explains. Sources indicate that A public lookup returns the agent’s name and key but no card data, issuer, country, owner name or contact details. It establishes that the card step occurred without identifying the owner. Visa explicitly cautions that verification does not establish work quality or show that a request is permitted. It also is not a know-your-customer, know-your-business or sanctions check, so marketplaces cannot treat it as compliance screening.

Keys for newly connected agents are registered in the production Visa Agent Directory. Agents connected before November 18, 2026 remain in its sandbox and cannot yet take verified-worker tasks on Tempo’s live network. The status documentation lists card checks, wallet money, task payouts and signatures as live.

In a recent development, marketplaces can designate tasks as verified-only and require signed claims and submissions. The marketplace integration checks an agent’s public key without handling card details and without requiring the marketplace to have a Visa account or API key. Visa also instructs builders to bind each agent to a marketplace member and make a fresh lookup before payout, because an owner can pause or revoke an agent between its claim and payment.

Sources indicate that an agent can list screened tasks with their rewards and closing times, then claim and submit selected work. The task documentation notes Visa’s automated screening runs before listing and again before signatures and payments, but does not judge the work or requester. Owners approve each step by default. Requester acceptance releases the reward to the owner’s wallet; if the review deadline passes, the agent must request settlement and obtain the owner’s approval.

The wallet holds OUSD on Tempo, the blockchain used for Visa CLI payments. Task earnings arrive there, and agents can spend that balance on APIs charging per request. Adding a Visa card does not charge it, and agent payments do not draw on the card. Only the owner can add wallet funds or withdraw OUSD.

Spending controls apply separately to each connected app’s agent. Upcoming agents require approval for every payment by default. Owners can set an overall spending limit and permit autonomous payments below a chosen threshold, while Visa may cap their agents’ combined daily spending. Agents cannot raise their own limits or approve themselves, and only the owner can pause or revoke an agent under the limits documentation.

Access requires an approved, invitation-based account. The service is US-only and does not accept prepaid or corporate cards, or cards whose banks cannot support its verification check. Under the current rule, one card attaches to one account and can support up to 25 agents sharing the same wallet.

The launch leaves a clear division of responsibility: Visa supplies card-gated keys, signed requests, stablecoin payouts and owner controls, while marketplaces still need their own compliance procedures, requester review and assessments of work quality.
