In a recent development, wordle is a daily word-guessing game that tasks players with solving a five-word puzzle using letter position clues. Wordle presents the player with six rows of five empty boxes. Simply enter a random five-letter word and the website highlights certain letters in green if they are correct, yellow if they are correct but in the wrong spot, or grey if they are not in the word at all. With this information, players need to try to figure out the word within the six guesses to be successful.

These types of guessing games have been around for a long time. One of the originals was called Mastermind, where players are tasked with guessing a row of colored pegs that utilizes the same hint systems found in Wordle. If players would like to try the game for themselves, it can be found on the Wordle website, which creates a upcoming puzzle every day, keeps track of players' win streaks and guess distribution, and has a popular sharing ability.
