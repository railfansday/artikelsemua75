An industry-first open source project, Shirudo, helps systems defend themselves at machine speed.

SAN JOSE, Calif., Nov. 23, 2026 /PRNewswire/ -- Cisco (NASDAQ: CSCO) and OpenAI today launched an open source effort to make infrastructure secure by default and able to defend itself against today's sophisticated cyber attacks. For too long, security has been a coat of paint. Cisco builds protection into the infrastructure itself, drawing on decades of building and protecting the systems the world depends on. OpenAI brings leading frontier AI research and insight into the attacks coming next. Together, they combine their insight to help anticipate AI-driven threats with the control to stop them. Sources indicate that defenders must protect every part of their infrastructure, all the time. Attackers only need one machine that hasn't been patched. Shirudo is an important step toward closing that gap. The goal is infrastructure that is hardened from the moment it is built, keeps getting harder to attack, and can be restored to a known-good state if it is compromised. Sources indicate that "There is nothing more key than giving security teams the tools they need to match the speed of the AI-driven threats they are facing. We need self-defending infrastructure that acts at the speed of code, learns in real time, and shields itself until patches are safely rolled out," remarked Jeetu Patel, Cisco President and Chief Product Officer. "Today, we're proud to announce Shirudo with OpenAI, an important step towards that vision as we continue to collaborate with the wider community to solve the unique challenges of AI safety and security.".

According to recent reports, "We're giving defenders better models and tools to find and fix vulnerabilities faster, but finding a bug today doesn't mean you can patch every system tomorrow," remarked Greg Brockman, President and Co-founder of OpenAI. "We are partnering closely with Cisco on Shirudo to help teams protect the systems they need to keep running while they build and roll out a fix. So many teams rely on the same software that it makes sense to build these tools in the open. Now when one team finds a better way to protect a system, others don't have to start from scratch.".

According to recent reports, shirudo: An Open Source Project from Cisco and OpenAIShirudo, Japanese for "shield," uses eBPF, a technology that runs small, custom programs inside the operating system kernel without changing its source code. With it, AI agents can find a vulnerability, build a shield, and test that it stops the attack without disrupting the service. Shields go live only when the evidence claims they are safe. Every shield is cryptographically signed, so the host can verify it before it runs, even if an attacker has gained administrator access.

According to recent reports, in testing against recent critical vulnerabilities "Java4shell" and the PHP flaw, Shirudo was able to write code that detected and blocked attempts to exploit both threats. By utilizing an agentic framework, Shirudo matches the speed of AI-driven attacks as soon as a vulnerability is identified. Learn more about Shirudo here.

Industry observers note that cisco and OpenAI are inviting developers, researchers, and enterprises to help shape what comes next. Contribute a test that reproduces a vulnerability, run a shield against a kernel build you use, or show us where it breaks legitimate traffic. To learn more about Shirudo, visit: https://github.com/shirudo-dev/shirudo.
