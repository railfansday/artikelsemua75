A closing tag with a newline in an included file Your main file can be perfect and still fail, because an included file ends with ?> followed by a newline. That newline is output too. Fix: omit the closing ?> tag entirely in files that contain only PHP. PHP's own style guidance recommends it, and it removes a whole class of invisible accidents.
