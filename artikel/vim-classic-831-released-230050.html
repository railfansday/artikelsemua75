It has been revealed that the README.md for YouCompleteMe on GH says the minimum version of Vim is 9.1.0016, which seems to address this since Vim Classic is a pre-9.0 fork. Likewise, Vim Classic is pretty explicit that it's a fork from the 8.x days, so it should go without saying that anything that requires Vim 9.x on is probably going to be incompatible.

It has been revealed that for my purposes that's fine: I don't use tons of plugins and as far as I was concerned, Vim was pretty much feature complete around Vim 7.0. All I require now is security updates and ensuring that it continues to compile on more recent versions of Linux... others' mileage may vary, of course. :-).

According to recent reports, one thing that tree-sitter (which, I believe is a NeoVim thing, but maybe Vim 9.x had it) enables is that C++ syntax highlighting is no longer an absolute anchor on any kind of performance. That noted, I have gone all-in on quite a number of NeoVim things since migrating….
