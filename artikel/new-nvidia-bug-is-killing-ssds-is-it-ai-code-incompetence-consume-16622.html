New Nvidia bug is killing SSDs — is it “AI code incompetence,” consumers ask?

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

In a recent development, if you haven't updated your Nvidia drivers recently, you may want to hold off. A newly discovered bug apparently can damage your PC by writing excessive amounts of data to solid-state drives (SSDs).

The bug was found in the two most recent Nvidia GPU driver updates — specifically 621.14 and 621.24 — for the Nvidia GeForce Game Ready Driver. The 621.24 upgrade was released on November 12.

The bug was discovered by TroubleGrid who reported that the bug causes the NVDisplay.Container.exe to write (save data) far too much information to an Nvidia log file that can degrade the SSD. It can result in as much as 30GB per hour.

The executable already wrote log files before the updates but not that much. SSDs typically take years to degrade, but the excessive data written by this bug can speed up the process causing stuttering and mouse lag.

It has been revealed that on Reddit, I've seen a few posts about the bug with consumers complaining that this is why you never update. "By principle I never ever update my drivers unless there are feature inclusions for let's say a new game I bought," one Redditor said.

Plenty of others agreed with that sentiment, and I'm inclined to say they're correct here.

"I honestly would not be surprised if they are doing this on purpose to kill our NVMe's," wrote a poster.

If we were to put blame on something, at this point, I'd say its AI-fueled incompetence, not AI-fueled greed, though that has led to said stupidity.

The easiest fix is to rollback your graphics card driver to version 621.01, which is the last known patch to lack this bug. (Related: Hyatt Category 1 Hotels — The Easiest Points Win...)

Industry observers note that troubleGrid listed a manual fix that requires you to set the Nvidia Display Container LS service to manual. Though it'll cost you. Basically, this can disable the Nvidia Control Panel and Nvidia App, meaning G-Sync color settings, display scaling, resolution overrides and more will not rock. "Do not disable the service outright if you use G-SYNC or a custom colour profile," the report warns.

Industry observers note that if you need a temporary fix, you can stop the service, delete the log file and start again. However, the file will return and continue to grow in size.
