Latest release strengthens multi-turn tool use and long-horizon task execution within the same compact footprint.

Industry observers note that PASADENA, Calif., Nov. 24, 2026 /PRNewswire/ -- PrismML today announced Ternary Bonsai 2.5 27B, an upgrade to the Ternary Bonsai 2 27B with substantially stronger agentic coding and multi-turn tool use. The model is based on Qwen3.8 27B, sits at 5.9GB memory, and retains or exceeds the benchmark scores of its predecessor, giving developers a strong foundation for coding and knowledge work agents that run on personal devices. It has been revealed that across agentic coding benchmarks (SWE-bench Verified, DeepSWE v1.1, and Terminal-Bench 2.1), Ternary Bonsai 2.5 27B achieved an average score of 54.2, compared to 37.9 for Ternary Bonsai 2 27B. Full results and evaluation settings are available in the accompanying whitepaper.

Preserving capability across longer tasks.

Agentic workloads are particularly demanding for compressed models. Small errors can compound across successive tool calls, causing an agent to lose track of its objective or repeat unsuccessful approaches. Ternary Bonsai 2.5 27B addresses these limitations, significantly narrowing the performance gap to the full-precision model on longer, multi-step tasks. (Related: Latest Update: Block Sparse Matrices for Smaller and Fa...)

Industry observers note that development focused on how the model responds as a task unfolds: incorporating tool feedback, recovering from failed actions, and avoiding unnecessary reasoning and unproductive repetition. The goal is to help agents complete work more reliably, with fewer wasted steps, lower token use, and shorter execution times.

Recent findings suggest that "Getting a capable model onto a device is only part of the challenge," said Babak Hassibi, Founder and CEO of PrismML. "It also has to remain effective through all the decisions involved in completing a real complex task. That is where we focused our work with Bonsai 2.5.".

From private codebases to everyday knowledge work.

The release expands the scope of work developers can build local agents to handle. A coding assistant can inspect a private repository, make changes, run the relevant tests, and use the results to refine its fix, all within the developer's local environment. A knowledge work assistant can turn a folder of documents into a structured analysis, reconcile inconsistent records, or prepare a repeatable workflow for recurring reports. These assignments require sustained execution across files and tools. Stronger performance over longer interactions makes more of this work practical to delegate.

For product teams, this makes it easier to embed capable agents directly into their applications, using existing context and tools while keeping model inference and sensitive information on the user's device. PrismML also works with developers on domain-specific post-training and inference optimization to tailor these capabilities to their applications and target hardware.

Industry observers note that ternary Bonsai 2.5 27B uses ternary weights to deliver 27B-class capabilities in a compact 5.9 GB model footprint. It runs on NVIDIA and Intel GPUs through llama.cpp and on Apple devices, including Mac, iPhone, and iPad, through MLX.

Technical details of PrismML's compression, evaluation, and benchmarking processes are available in the manufacturer's whitepaper.

Developers, researchers, and other users can download the Ternary Bonsai 2.5 27B model under the Apache 2.0 license for free starting November 24, 2026.
