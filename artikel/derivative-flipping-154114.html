Which means that if we're interested in computing the Laplacian in 2D we only ever need to track 4 coefficients. We don't need to keep track of the full Hessian. In fact we can replace the polynomial on the right of the pairing with a 4-vector and replace apply with code to act directly on that representation.

Sources indicate that we have just rediscovered the method for computing Laplacians I described many years ago at Computing errors with square roots of infinitesimals. But now it's more general and we can use this for any constant differential operator. For example the biharmonic operator corresponds to the polynomial \((\sum_i x_i^2)^2\). When you compute all of the possible expressions that can arise from applying the \(\partial_i\) operator it forms a far smaller space than you might get from naively carrying along the power series up to degree 4.
