In a recent development, from this message you are meant to intuit that RPython did not enjoy that two different types flowed into the double function. It helpfully tells you that there was a UnionError when trying to reconcile the SomeChar and SomeInteger types that flowed into the function’s first parameter. It then gives you a pointer to the offending line and an IR dump.

This happens because RPython requires function parameters to be monomorphic. Though the variables are syntactically untyped, RPython computes a type analysis to discover what type each variable should be. When "a" and 3 both flow into x, boom, complaint.2.
