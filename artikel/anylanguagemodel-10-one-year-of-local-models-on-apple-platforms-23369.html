📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

According to recent reports, last November, we introduced AnyLanguageModel on this blog: a drop-in replacement for Apple's Foundation Models framework that lets you choose the model and provider your app uses. We heard from app developers who were curious about local models but weren't always sure how to get started. They also wanted to avoid the added complexity of supporting multiple inference providers. AnyLanguageModel grew out of that feedback.

Sources indicate that local and hosted inference each have their strengths, and both have a role in building this newly introduced generation of intelligent apps. A shared API makes it easier to choose the right model for each task.

Hosted providers get the same features as local models: guided generation, tool calling with streaming, and token usage on responses.

Reasoning is now part of the transcript too. When you switch providers, reasoning blocks are automatically omitted from requests if the upcoming provider can't replay them.

AnyLanguageModel also runs on Linux, so the same code can work on a server.
