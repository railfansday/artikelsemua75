[$] Zellij manages terminal workspaces with style

Zellij is a relatively new entrant in the terminal-multiplexer category. Like GNU Screen and tmux it gives consumers the ability to manage a workspace inside a terminal with split panes, provides session management, and so forth; but Zellij also includes a web server for browser access to a terminal session, is extensible via a plugin API, and is likely more beginner-friendly than its predecessors. Its most recent release, version 0.46, adds a standalone terminal emulator, a built-in inbox for notifications, and a settings screen so users can configure the application without fussing with configuration files. While the low version number might suggest that it is not yet ready for serious use, it seems stable and full-featured enough to meet the needs of many users.
