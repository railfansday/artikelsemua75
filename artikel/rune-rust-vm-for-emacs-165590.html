The project is defined by a main package rune, which depends on the crates included in the crates directory. One of those is the rune-macros crate, which defines the defun proc macro for defining builtin functions. The rest of the code is contained in src/. The modules are described below.

See the architecture doc for more info on the structure of Rust Emacs internals.

Sources indicate that this project is moved forward by trying to load upcoming elisp files and seeing what breaks. The best way to do that is with cargo run, which will load the at the moment bootstrapped files. The bootstrapped files are located in main.rs as part of the load function.

It has been revealed that rune includes the `assert_elprop!` macro, which enables property testing against GNU Emacs. This macro works by sending the same Lisp form to both Rune and Emacs and then comparing their results. It can also be used in conjunction with the `proptest` crate.
