Groundcover launches Agent Investigations, a shared workspace for AI agents and engineers

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

UPDATED 09:00 EST / NOVEMBER 19 2026.

Sources indicate that observability organization groundcover Inc. today declared the launch of Agent Investigations, a shared workspace designed to allow groundcover’s artificial intelligence agents, a team’s own coding agents and on-call engineers to work production incidents together. (Related: Tiny Agents: an MCP-powered agent in 50 lines of code...)

Agent Investigations is aimed at the problem of scattered findings as AI agents take on a bigger role in incident response. When production goes down, several engineers often point their own agents at the same issue, with each agent working in isolation, according to the company. What those agents conclude, it says, is end up in private chats, tickets or Slack messages out of view of the rest of the team. (Related: NVIDIA brings agents to life with DGX Spark and Reachy ...)

Recent findings suggest that investigations in the new workspace are started automatically by groundcover once a monitor issue opens. Engineers also have the option to launch one manually from the groundcover interface or from a button in Slack.

Recent findings suggest that on groundcover’s side, the work is split between two agents. The first, known as the Investigator agent, is mentioned to build a graph of questions and hypotheses before testing each one against groundcover’s logs, metrics, traces and Kubernetes data. Supporting graphs are attached to each of its findings.

Industry observers note that reviewing every proposed conclusion is the job of the second, a Moderator agent. The Moderator, which is the only agent allowed to close a hypothesis, sends back any claim that lacks supporting findings. Doing so is remarked to separate generating a possible explanation from validating whether the evidence actually supports it.

Ending each hypothesis is a structured assessment that either supports or refutes it. The tech giant claims teams get a set of tested answers to read through instead of pages of generated text.

According to recent reports, agent Investigations also offers access for outside agents, including Anthropic PBC’s Claude Code and OpenAI Group PBC’s Codex, through groundcover’s Model Context Protocol server. Connected agents can read from and contribute to the same investigation, with agents used for business intelligence and product roadmapping also able to take part. In October, groundcover launched agent-to-agent observability tools that let outside coding agents hand production investigations to its own agent.

Hypothesis status and assessments post to the Slack thread tied to the original alert. With replies posted in that thread also fed back into the investigation, engineers are able to steer the work from inside the incident conversation.

According to recent reports, “Every engineer now has an agent, but each of those agents investigates on its own and findings end up in a chat window,” mentioned co-founder and Chief Executive Shahar Azulay, who started groundcover in 2021 with Yechezkel Rabinovich. “Agent Investigations gives humans and agents one place to work an incident, where every hypothesis is tested against production data and every conclusion has to be backed by evidence.”.

Omer Mayer, senior product manager at groundcover, said the wait while agents are working and the on-call engineer has nothing to look at is often “the hardest stretch of an incident.” Engineers using Agent Investigations instead get to watch, he said, as each hypothesis is supported or ruled out in real time.

Recent findings suggest that the graph the Investigator builds also serves as the record, noted to show how a team reached the root cause, including the hypotheses that were ruled out along the way. According to the firm, keeping the monitor, Slack thread, investigation and conclusion linked means nobody has to piece the history back together from separate tools after an incident closes.

It has been revealed that powering the investigations is the full-fidelity telemetry collected by groundcover’s sensor. Because groundcover uses a bring-your-own-cloud architecture, the data remains in the customer’s own cloud account even while agents are querying it.

Sources indicate that agent Investigations is available to groundcover customers whose backends have AI enabled. The tech giant will demonstrate it at Amazon Web Services Inc.’s re:Invent conference in Las Vegas Nov. 30-Dec. 4.

Groundcover has raised $160 million to date, including a $100 million Series C round led by One Peak in July.
