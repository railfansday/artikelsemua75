Recent findings suggest that you can get a Windows virtual machine for free and stay within the license terms, but every route is limited in time or credit. Download a Microsoft evaluation ISO and run it in Hyper-V or VirtualBox, use Windows Sandbox for throwaway tests, or use free cloud credit on Azure. Pick by what you need the VM for, and set shutdown and budget limits so a free trial does not turn into a bill.

This guide is for students who need Windows to practice administration or test software, and for IT staff who need a disposable lab. At the end you will know which legal route fits your computer, how to switch it on, how long it lasts, and what can cost money. Sources indicate that the key point: none of these gives you a permanent free Windows license. A free VM runs software that you already have a license for, or an evaluation that expires.

The Microsoft Evaluation Center is the most direct legal route and works offline once downloaded.

Recent findings suggest that on 2026-11-23 the evaluation page listed "Windows 11 Enterprise, version 26H2" as an x64 ISO and an Arm64 ISO, plus "Windows 11 Enterprise LTSC 2024" as an x64 ISO. Microsoft describes it as "the full-featured software for a 90-day evaluation" and states a product key is not required. You register to download, and Windows prompts you to activate after installation with a Microsoft account.

Know the end state before you start. Microsoft's page claims that if you do not activate or the evaluation expires, the desktop background turns black, a notice says the system is not genuine, and the PC shuts down every hour. It also says installing from the ISO cannot be uninstalled and the recovery partition cannot restore a previous Windows, so install it in a VM, not on your main computer. It has been revealed that the Windows Server 2025 evaluation page said on 2026-11-23 that the edition expires in 180 days. It offers a 64-bit ISO, a 64-bit VHD, and pre-built images on Azure. The ISO covers Datacenter and Standard, each as Server Core or Server with Desktop Experience. The VHD is English only. Evaluation versions must be activated over the internet in the first 10 days or they shut down automatically.

Use the VHD with Hyper-V Generation 1 or the ISO if you want to practice the install. If you only need a lab for Active Directory or Group Policy practice, this is the better choice because 180 days covers a full semester.

It has been revealed that microsoft used to publish ready-made Windows 11 development virtual machines on a developer download page. On 2026-11-23, that old address redirected to the general Windows developer tools page on Microsoft Learn, and that page did not list any VM images. We could not confirm that the images are right now offered, so use the evaluation ISO instead and treat any site that claims to offer them with caution.

Hyper-V is built into Windows as an optional feature; there is nothing to download. Microsoft lists these requirements: Windows 10 or 11 Pro or Enterprise, a 64-bit processor with Second Level Address Translation (SLAT), CPU support for VM Monitor Mode Extension, and at least 4 GB of memory. The Hyper-V role cannot be installed on Windows 10 Home or Windows 11 Home.

Microsoft says you should see "The operation completed successfully." The graphical route on Windows 11 is Control Panel, Programs, Programs and Features, Turn Windows Features on or off, then select Hyper-V and OK.

After the restart, open Hyper-V Manager, choose Upcoming, then Virtual Machine, and point the installation media at the evaluation ISO. Give a Windows 11 VM at least 4 GB of memory and 2 virtual processors if your computer has the room; Windows 11 itself has its own hardware requirements, so check them on Microsoft's device specifications page.

Sources indicate that microsoft warns that third-party virtualization apps such as VMware Workstation and VirtualBox rely on processor features Hyper-V also needs. You can install both, but if you start a VM in the other app while the Hyper-V hypervisor is running, the VM might not start or might run unreliably. Pick one for each work session.

Windows Sandbox is a disposable, lightweight desktop. It is not for keeping files or installing a lab; it is for opening something risky once and throwing it away.

Sources indicate that microsoft lists the prerequisites: AMD64 or Arm64 architecture, virtualization enabled in the BIOS, at least 4 GB of RAM (8 GB recommended), at least 1 GB of free disk space and at least two CPU cores. In a recent development, if the Windows Sandbox option is missing, Microsoft says your computer does not meet the requirements. Also note that beginning in Windows 11 version 24H2, inbox store apps such as Calculator, Photos, Notepad and Terminal are not available inside it.

VirtualBox is free third-party virtualization software that runs on Windows Home as well, which Hyper-V cannot. It does not supply a Windows license, so install an evaluation ISO or a Windows version you already own. We did not verify VirtualBox's current version or extension license terms in this run; check the VirtualBox downloads page and its license text before using it at work.

A cloud VM saves your PC's memory and is reachable from anywhere, but it is the route that can produce a bill.

According to recent reports, the Azure free account page on 2026-11-23 offered a "$200 credit" to use on Azure services within 30 days. You must move to pay-as-you-go within 30 days or after using the credit, whichever comes first, to keep services running. New customers also get "750 hours each of B1s, B2pts v2 (Arm-based), and B2ats v2 (AMD-based) burstable VMs" for 12 months. That wording covers specific burstable B-series sizes; the page does not say it covers every Windows VM, so check the size and the price in the portal before you create it. A non-prepaid credit or debit card is required, and you may see a one-dollar verification hold.

The Azure for Students page highlighted a "$100 credit" to use within 12 months, renewable annually while you remain a student, with "No credit card required." It is for full-time university students signing up with a school email, one account per person. For classroom practice this is usually the safer route because there is no card to be charged by accident.

Recent findings suggest that AWS changed its free tier to a credit-based model. The AWS Free Tier page on 2026-11-23 noted fresh accounts receive $100 immediately and can earn up to $100 more by exploring services, up to $200 in total, and that the account closes six months after opening or when credits run out, whichever comes first. The free plan is limited to select services; the page did not say which EC2 instance types are eligible, so check the console before launching Windows, which carries a license charge in AWS pricing.

Recent findings suggest that google Cloud's free trial gives "$300 in free Welcome credit which is valid for 90 days," but the documentation lists creating VM instances based on Windows Server among the things the free trial does not allow.
