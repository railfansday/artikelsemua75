Recent findings suggest that exposure management firm Astelia Inc. today revealed the launch of autonomous network mitigation, a fresh capability that allows organizations to block artificial intelligence-driven exploits at the network level, even when a patch isn’t available or can’t be applied. In a recent development, the latest capability has been designed to address what Astelia states is the problem of frontier AI models cutting the time to exploit to almost zero, leaving manual triage and remediation unable to keep up. Astelia argues that autonomous remediation isn’t a viable option for large enterprises, where every patch requires a change window so it doesn’t break vital business processes. In many cases, there is also no patch to apply because the vendor hasn’t released a fix yet or, for older and end-of-life systems, never will. (Related: Transformer-based Encoder-Decoder Models...)

“For years, security teams have been told to patch faster,” stated co-founder and Chief Executive Alon Noy, adding that the advice “stops working when the exploit arrives before the change window does.”.

In a recent development, autonomous network mitigation is designed to block the path an attacker would use to reach a vulnerable system instead of changing the system itself. Mitigations are applied automatically within policies the organization sets. Nothing on the asset is changed, allowing business-critical systems, including operational technology, to stay online.

Underpinning the service is Astelia’s reachability analysis, which maps an organization’s real network topology and applies agentic AI to analyze the requirements of each exploit. By correlating exploit conditions with network topology, the platform identifies which vulnerabilities are reachable by attackers and through which paths. In one enterprise deployment, approximately 40 million vulnerabilities were reduced to fewer than 2,000 that were reachable, according to the manufacturer.

Key features of autonomous network mitigation include the ability to identify the most effective choke point on an attack path and drive the mitigation through an organization’s web application firewall or intrusion prevention and detection system. A single rule at a choke point is said to protect every vulnerable server behind it, compared with one change per server when patching. Because mitigations are only applied to paths that have been proven reachable, the service doesn’t add rules for exposure that doesn’t exist.

Every mitigation applied by Astelia can also be rolled back, something that isn’t always possible with a patch. That is mentioned to allow teams to act swiftly without putting business operations at risk.

Sources indicate that autonomous network mitigation can be deployed through Astelia Agents, the manufacturer’s suite of AI agents, as a dedicated agent that applies mitigations on its own. The agent can also be connected with other agents to respond to urgent threats such as zero-day vulnerabilities and critical disclosures. Astelia gave the example of the PHP2Shell remote code execution flaws disclosed in October, which left end-of-life PHP servers with no official fix.

Industry observers note that each organization sets its own guardrails on how mitigations are applied. Owners can require human approval for specific environments or actions, according to the firm. Every action is logged and can be audited. Analysis on the Astelia platform continues to run on read-only integrations, with mitigation actions using scoped permissions that each organization enables and controls.

Autonomous network mitigation initially supports web application firewall and intrusion prevention and detection rules, with support for firewall rules planned in the future.

Founded in 2024 by former leaders of the Israeli National Red Team, Astelia is a venture capital-backed firm that raised $35 million in combined seed and Series A funding in February. Investors in the company include Index Ventures, Team8 and Holly Ventures.
