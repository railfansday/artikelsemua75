📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Microsoft has been updating Windows 11 to improve performance on PCs with 8GB of RAM, including by making various apps more efficient and responsive. There are ways for people to boost performance and clean up their system as well, which is particularly key at a time when upgrading a PC's RAM and storage can be debilitatingly expensive.

A quick and easy way to free up some storage space — and a process that many folks stand to benefit from having as part of their regular system maintenance — is to clear the browser cache. This stores certain aspects of websites on your system, such as images, style sheets and scripts. The cache can speed up web browsing and make sites load faster since it recycles parts of webpages that stay the same. (Related: Industry News: Block Sparse Matrices for Smaller and Fa...)

Recent findings suggest that the cache is especially useful when you're looking at several pages on a website, since you won't have to re-download elements that are consistent across the domain. Still, it's good practice to clear out the cache now and again to remove cruft that builds up over time, especially data from sites that you rarely visit. Sources indicate that if you're a Windows user and you're sticking with that platform's default browser, that means you're accessing the web through Microsoft Edge. Clearing the cache in Edge takes just a few moments of your precious time.

First, you'll have to decide if you want to wipe the cache only on the system you're using or on all synced devices. If it's the former, you'll need to turn off the sync function first. To do that, go to the Settings and more menu in Edge (the button with three dots next to the address bar), then Settings > Profiles > Sync > Turn off sync.

Recent findings suggest that next, you'll want to go to the Clear browsing data page. From the Settings menu, you'll find that by clicking on Privacy, search, and services > Clear browsing data. Next up, click on Choose what to clear.
