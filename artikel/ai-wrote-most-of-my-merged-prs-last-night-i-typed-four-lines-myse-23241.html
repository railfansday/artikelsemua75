Sources indicate that this week, maintainers merged three of my pull requests into projects I don't own. Then, a little before midnight, I typed my first fix by hand.

According to recent reports, it was four lines. I was nervous anyway.

I'm new. Not "new to Rust" new. New new. Most of the code under my name was typed by Claude Code. My job so far has been the part after the AI claims "fixed": running it, checking it, and asking whether anything would notice if it was wrong. (Related: What I do every time I get an IRS notice...)

In a recent development, that habit turned into a tool, Bite. It takes a "fixed" commit back out of your code and reruns your tests. If they still pass, no test guards that fix.

It has been revealed that this week I decided "checking the AI" isn't the same as knowing how to code. So I started learning.

My language project, Past Forever, has a command-line runner. When a program crashed, the runner printed the error and then told the computer everything went fine. Exit code 0. Any script or CI job running it would shrug and carry on. (Related: Future Value Calculator: How to Project Your Investment...)

Recent findings suggest that claude walked me through it step by step. I typed every character in the GitHub web editor, ran the tests, and then had to explain it back in my own words before merging. My explanation was one sentence. It counted.

Sources indicate that what I learned: a program has two ways of answering. What it prints is for people. The exit code is for other programs. Mine was lying to the programs.

Sources indicate that docling-pipelines #686 (merged). The reviewer asked for five changes. One was that when you escape text, "the backslash must be escaped first." I pushed one commit that covered every point, and it was approved the same day.

django-modeltranslation #831 (merged). Bite found this one: two settings helpers reset a value to nothing when they finished, instead of putting back what was there before. I opened it on October 27. It sat for three weeks. I sent one polite nudge. It got merged this week.

Sources indicate that django-modeltranslation #832 (merged). The maintainer requested a change: don't patch Django when the file loads, do it in the app's ready() step, with a guard so it only happens once. I made the change, added a test, and it was merged the same day. My PR description remarked up front that I wrote it with help from Claude Code.

wardenIQ is a test-case generator that can run on a local AI model. I test it on a CPU-only setup, which turns out to be useful: I'm the slow machine.

It has been revealed that outside contributors have been helping on my repos for weeks. This week two more showed up.

Sources indicate that imshah-id opened Trawl PR #28. I reviewed it and asked for changes. The day before, I was the one getting change requests.

jeelthacker1 asked to take Bite #251. I mentioned it's theirs.

AI did most of the typing in everything above, and helped draft this post. Every link and number in it was checked against the source. The week's real change is that I'm starting to read what it writes, and sometimes write it myself.

If you're also learning with an AI next to you: make it explain, then explain it back. And check its "fixed" claims. Some of them don't hold.

Sources indicate that I credit everyone who breaks something. There's a Hall of Fame with a Breakers list.
