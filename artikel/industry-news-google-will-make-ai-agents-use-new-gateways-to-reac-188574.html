Industry News: Google will make AI agents use new gateways to reach Gmail and Drive

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

It has been revealed that google has made its Workspace MCP servers and CLI generally available and notes AI agents must use them instead of existing REST APIs from February 1, 2027. Every call is checked against manufacturer policies, sensitive actions need user confirmation, and a latest addendum bars AI tools from training on Workspace data.

According to recent reports, google will require AI agents to reach Gmail, Drive and other Workspace apps through new, dedicated gateways, it mentioned on Tuesday. Regular apps can keep using Workspace’s existing APIs, but agents must switch by February 1, 2027. (Related: How to train a fresh language model from scratch using ...)

In a recent development, the gateways are Workspace MCP servers, which use a common standard for linking AI tools to apps, and a command-line tool. Both are now generally available. Google put an early CLI version on GitHub in March. (Related: My Journey to a serverless transformers pipeline on Goo...)

Industry observers note that google claims its APIs were built for apps that work at human speed, where a valid login meant the user wanted the action. Agents act on their own at machine speed. So every request now gets checked against firm permissions and data-loss rules.

Agents can draft emails and summarise documents on their own. But they need a person’s sign-off before sending email, changing Drive sharing or making bulk edits.

Each agent also needs its own sign-in ID with tight limits and usage quotas. Google already gives its Gemini coworker agents their own accounts. It will begin billing for that usage on April 1, 2027.

A upcoming AI Tools Addendum adds rules on data. AI tools cannot use Workspace data to train models or build rival services, and cannot scrape it. They must also delete it when a user disconnects.

Google also tells developers to screen for prompt injection, hidden commands in emails or files that can hijack AI agents. Some controls are still to come, including letting customers see and revoke agents’ access themselves.

Industry observers note that other firms are drawing lines too. In October, Charles Schwab said it blocks outside agents from moving client money.
