Recent findings suggest that cachyOS, a performance-focused distribution based on Arch Linux, has announced its November 2026 release. Notable changes in this release include a new recovery environment ("cachyos-recovery") for rolling back broken systems, Easy Anti-Cheat (EAC) v2 support for games that require EAC to run, version 2.0.0 of the CachyOS Package Installer, and more.

Industry observers note that 1. DRM and anticheat are, to a large part, one and the same, including that they're trying to best-effort solve a theoretically impossible problem by locking down clients. (Related: Industry News: Simple considerations for simple people ...)

In a recent development, not purchasing DRM-requiring games is really the best way to do this. Game studios certainly have the right to release games that require it. It's just better if no one buys them then. (Related: Deploy Hugging Face models easily with Amazon SageMaker...)

According to recent reports, after that came Secure Boot, which when enabled (and the security hysteria is that you must always have it enabled, even though its driving use case of "not allowing any untrusted code to run before the antivirus starts" is not very relevant for Linux) makes it harder to use a self-compiled kernel. It seems that, outside of source-focused distributions, we've grown complacent and got too comfortable letting someone else compile the software we use.
