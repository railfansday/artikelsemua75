Recent findings suggest that I started programming in Python around 2015, when I was 8 yrs old. Back then there was no cute AI to come along with you and help you build your dream project from scratch. There was only the documentation, Stack Overflow and God's grace. I studied programming by reading through pages and pages of God-forsaken forums that might have been written during the Stone Age and I see the kids these days are asking about the for-loop syntax to ChatGPT (not even Google, just straight up ChatGPT 🫠 ) . Simply depressing.

Every software product deployed nowadays has at-least one of its parts written, corrected or reviewed by AI. Because of this, students like us have no other way to but to use AI so that we can keep up with the competition. (Related: What I do every time I get an IRS notice...)

According to recent reports, but I genuinely reminisce the old, golden days of programming where quality mattered more than quantity. So, as a form of AI detox I decided to create a physics engine from scratch without the help of any AI. (Related: See where votes are being counted in Senate and House m...)

This is Day 1 of building a Physics engine without any AI.

Project Name : pluto Github Repo : [https://github.com/kelvinbkenn/pluto] Language : C++ Bulid system : CMake Graphics : SFML Vectors : Custom.

Industry observers note that now, the actual reason I started this project is so that I can learn C++ and CMake. This is my first ever project in C++ so be nice in review.

Initially I planned to use raylib instead SFML, but the idiomatic API of SFML seemed like a better fit for the project. But I have a plan to Rust for graphics later in development.

For the vectors and linear algebra stuff, I decided to go with a custom implementation.

That's all for now. I have my End semesters going on, so after that you can expect regular updates. Wish me luck!! Bye guys!!
