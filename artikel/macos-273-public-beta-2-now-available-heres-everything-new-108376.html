It has been revealed that after releasing developer beta 2 of macOS 27.3 earlier this week, the firm is now rolling out the public beta for owners looking to try the latest features ahead of next month’s official release. Here’s what’s coming.

Last Monday, Apple released macOS 27.3 beta 2, with upcoming privacy controls for Full Disk Access and automation tools, and the availability of Apple Intelligence in China. (Related: Supermicro sued by shareholders over claims Nvidia exec...)

Those came alongside several upcoming features and tools on macOS 27.3 beta 1, including vertical tabs and adaptive dark mode in Safari, native Live Activities support, Markdown rendering in Quick Look, additional checks for potentially harmful content shared through iCloud links, and Siri AI support for Traditional Chinese, Norwegian, Turkish, and Vietnamese. And speaking of Siri AI, macOS 27.3 also expands the assistant’s capabilities across Apple’s own apps, allowing consumers to perform more complex actions in Messages, Music, Calendar, Photos, and Reminders, as well as manage files and folders. Apple is also introducing new tools for third-party developers to build more advanced Siri AI integrations using Markdown-based instructions.

While macOS 27.2 was a rather uneventful revision, macOS 27.3 is shaping up to be the biggest update since the release of macOS 27, and consumers on the public beta can now try out these new features ahead of their official release.

The release build for macOS 27.3 public beta 2 is 26C5047e, which matches the developer build.

If you’d like to join Apple’s free public beta program, visit beta.apple.com.
