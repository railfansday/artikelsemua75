npm stopped taking weekends

🌐 Source: Dev • 📅 21 Nov 2026 • ⏱️ 5 min read (985 words, 📚 Deep Dive)
💡 Key Takeaways
  • For six years, npm had the same week.
  • Then in spring 2025 that started to go.

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

For six years, npm had the same week. Five busy days, then a Saturday and Sunday at about a quarter of the pace, because the people running npm install were at work and then they weren't.

Then in spring 2025 that started to go. npm's downloads API has a daily total for the whole registry going back to 2015, so here's a weekend day as a share of a weekday, quarter by quarter, with PyPI beside it:. (Related: Meta’s ‘secret’ Black Friday sale just started, and it ...)

Days npm reports as zero and the Christmas fortnight are left out, and 2026 Q4 runs to 19 November. (Related: Jimmy John’s reveals Christmas Vacation meal with exclu...)

npm sat between 23% and 29% for 25 quarters in a row. It's at 47% now.

In a recent development, I was pulling those totals to see how substantial the AI boom looks from the registry's side, and the size is daft enough on its own. npm served 292 billion downloads in October 2024, 424 billion in October 2025 and just over a trillion this October.

Recent findings suggest that but a bigger registry with the same weekly shape would just be more of the same. The extra downloads since summer 2024 run at 54% on weekends, so whatever's adding them barely keeps office hours. That's close to PyPI, which has been up there as far back as the data goes.

Sources indicate that the obvious answer is all the latest apps AI tools are spinning up, installing whatever's in fashion. So I looked at packages nobody starts a project with any more.

Sources indicate that node-sass has been deprecated on npm since 2024, with a notice telling you to use sass instead. In summer 2024 it got about 286,000 downloads on a normal weekday and 62,000 on a weekend day. Now it's 155,000 and 82,000. Fewer people install it on a Tuesday than two years ago, and more do on a Saturday. TSLint, which told everyone to move to ESLint back in 2019, has nearly doubled at weekends with its weekdays flat. And left-pad, of all things, went from 21% to 59%.

Weekend downloads as a share of weekday ones, then and now (the data).

Summer 2024 is July to September, autumn 2026 is 1 October to 19 November. Medians, like the chart above.

Packages people still use moved just as much. When I checked 507 of the biggest on 14 November, 506 had gone up by at least 10 points, and none was still under 30%. Taking the biggest few hundred out of the registry's total leaves the line where it was, so it isn't a few giants dragging the average along.

Sources indicate that vaul is my favourite. It's a drawer component for React, and its README opens with "This repo is unmaintained". The last release was December 2024. In summer 2024 it got 76,000 downloads a weekday, and now it gets 5.4 million, because the Radix version of shadcn/ui's drawer is built on it, and AI app builders like Lovable start you off with the whole shadcn set. Lovable also puts its own Vite plugin, lovable-tagger, in the projects it makes, and of the 76,416 package.json files on GitHub that list it, 75,904 list vaul too.

So who's installing node-sass on a Saturday? A download count doesn't say who asked for it, but packages with a separate binary for each platform give a hint. esbuild ships one for Linux, one for Macs, one for Windows and a pile of others, and npm only fetches the one for the machine it's running on.

Linux stopped taking weekends before Macs and Windows did (the data).

Weekend downloads as a share of weekday ones for @esbuild/linux-x64, @esbuild/darwin-arm64 and @esbuild/win32-x64, worked out the same way as the first chart.

According to recent reports, linux started drifting in spring 2025, while the Mac and Windows binaries didn't budge all year. They only got going in 2026, and they're at 44% and 45% now to Linux's 54%. Rollup's binaries do exactly the same. Linux is also where the volume is: 59 million esbuild installs a weekday, up from 5 million in summer 2024, against 3.5 million for Macs.

According to recent reports, that gap rules out one boring answer. Anything that grabs packages wholesale, like a mirror or a security scanner, would fetch all three alike, and the three lines would have moved together. They didn't.

Most CI runners, containers and cloud sandboxes are Linux, so the first wave looks like machines. OpenAI's Codex cloud agent and Claude Code's general release both came out in May 2025, which lines up nicely and proves nothing. I can't read the Macs and Windows PCs. That could be people building things at weekends now that something else does the typing, or more CI on Macs, or both, and download counts can't tell them apart.

It has been revealed that the weirdest one I found is create-vite, the thing you run to start a upcoming Vite project. Scaffolders were always weekend-heavy, because starting a side project is a Saturday thing, and create-vite ran at 67% in summer 2024. It's at 93% now, on 12 times the volume. Vite projects get started on a Sunday nearly as often as on a Tuesday.
