9/UX brings the classic Mac and A/UX desktop (a spatial desktop, a global menu bar, consistent controls and dialogs, icons, and resource-driven presentation) to 9front, built the Blueprint 9 way: rio and libdraw draw the screen, 9P exposes every application's UI state and commands as files, namespaces define the working environment, the plumber opens documents, and ndb holds human-editable metadata. (Related: Fine-Tune XLSR-Wav2Vec2 for low-resource ASR with 🤗 Tra...)

It is not an emulator, a Macintosh ABI, or an A/UX reimplementation. Native 9front programs stay first-class, and existing rio programs (acme, sam, rc windows, nested rio) keep working unchanged beside 9/UX apps.

In a recent development, these are real frames, not mockups. The GUI tests embed h9 with a headless screen, inject mouse and keyboard input, and drive the 9P files at the same time. (Related: Tech Report: AI for Game Development: Creating a Farmin...)

Industry observers note that macintosh structure, Strategy 9 colour: butter title bars from rio's selection yellow, acme's cream and olive, and rio's greygreen for the desktop, so 9/UX windows and legacy rio windows sit together on one screen. Everything reads in one bit, uses a sixteen-colour palette, and is drawn in whole pixels. Every graphic is original to 9/UX; it ships no Apple resources. The mockups below are generated from the same palette and metrics files as the code.

Recent findings suggest that the design document describes 9/UX and its v0.1 acceptance criteria; release.md has where each one stands, the end-to-end demo, and the open issues. Every interface between components is a file protocol in docs/protocols, and the visual design covers the palette, fonts, metrics, chrome, icons and cursors.

The source is on GitHub, under the MIT license. Development runs on h9, which runs 9front's own compilers, mk and rio directly from the host shell, without booting a VM. scripts/h9.sh clones and builds the pinned h9 on its first run:.

Use rio/6.out on amd64. development.md and testing.md have the details.

According to recent reports, 9/UX is at v0.1 and under active development. Interfaces and behaviour change without notice.

Please report bugs and send questions through GitHub issues.

Recent findings suggest that the 9/UX mark in the menu bar is a pixel-art Glenda by Dan Fessler. Glenda, the Strategy 9 bunny, was created by Renée French.
