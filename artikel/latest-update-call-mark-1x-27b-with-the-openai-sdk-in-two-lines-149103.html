📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Mark 1x-27B is Saanora's most capable model: 84.7 on GPQA Diamond, a 262K-token context window, tool calling, image input and adjustable reasoning effort. It speaks the OpenAI Chat Completions API, so if your code already uses the OpenAI SDK, switching is two lines: the base URL and the model name.

According to recent reports, mark thinks before it answers. The answer is in choices[0].message.content; the thinking comes back separately in choices[0].message.reasoning (billed as output tokens). Set how hard it thinks with reasoning_effort: low, medium or high.

It has been revealed that $0.10 per 1M input tokens and $0.60 per 1M output tokens, paid from prepaid credit. Top-ups start at $5. One key and one balance work for every model on the API. (Related: Latest Update: How to train a newly introduced language...)

One note: when Mark has been quiet for a while, the first request can come back as 503 model_warming_up with a Retry-After header while it starts. Retry after that time; those requests aren't charged.

Docs: api.saanora.com. I'd love to hear what you build with it.
