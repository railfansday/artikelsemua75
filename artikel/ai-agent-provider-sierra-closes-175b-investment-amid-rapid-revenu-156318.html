Six months after its last funding round, artificial intelligence startup Sierra Technologies Inc. today revealed that it has closed a $1.75 billion late-stage investment.

Recent findings suggest that greenoaks and Lightspeed led the Series F deal. They were joined by a group of returning backers that included Alphabet Inc.’s GV fund.

According to recent reports, sierra sells a set of cloud services that enables workers to create AI agents without writing code. The centerpiece of the suite is Ghostwriter, which can automatically generate agents based on user-provided prompts and files. A software team, for example, could upload a set of bug reports and request an agent that can automatically group them by problem type. Recent findings suggest that ghostwriter checks the dataset that consumers upload for formatting errors before putting it to use. Once an agent is ready, the tool simulates user conversations to find potential bugs. Ghostwriter places particular emphasis on edge cases, unusual requests that can trip up an agent if they’re not addressed during development. According to recent reports, sierra also offers a second development tool called Horizon. It can be used to create agents that automate time-consuming tasks. A marketing team could build an agent that monitors user interactions with a product page over several months, finds areas for improvement and automatically makes the necessary optimizations.

Sierra powers customers’ agents using more than a dozen large language models. Simple requests are sent to latency-optimized LLMs, while more complex queries are processed by pricier frontier models. Sierra states that it also uses several internally developed algorithms.

According to recent reports, customers can manage their AI projects using a third Sierra product called Agent Studio. According to the tech giant, it includes over 40 connectors that enable agents to retrieve information from external systems. There’s also a tool for building custom connectors.

Recent findings suggest that agent Studio detects gaps in agents’ knowledge. Furthermore, it can automatically fix some of those gaps. The platform detects when a human support representative answers a customer inquiry that the help desk hasn’t encountered before and turns it into a knowledge base article. From there, agents can use the article to answer similar requests.

The studio also lends itself to certain other tasks. A collaboration feature enables multiple team members to review agent updates before they roll out to production. If a technical issue makes it past the review, developers can use a debugging tool to study what went wrong. The tool displays every single step of the workflow through which an agent processes prompts.

In a recent development, rounding out Sierra’s product portfolio is an AI assistant called Explorer. It can proactively flag notable business events without a prompt and search through a manufacturer’s internal datasets. In some cases, it also generates business advice.

Sierra’s latest raise, its third in 14 months, comes a few weeks after its annualized revenue topped $400 million. The company disclosed at the time that it had added nearly half the sum over the preceding quarter. Its customer base now includes half the Fortune 50.

Sierra will reportedly use the new funding to enhance its product portfolio and hire more salespeople.
